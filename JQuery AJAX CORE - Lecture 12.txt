a) Filters in Core.
>> >> Filter is used to perform some operations before or after action Method Execution.
Types of Filters:-
----------------------
a) Authorization Filters: These run first in the pipeline to determine if a user is authorized for the request. If authorization fails, the filter can short-circuit the request immediately.
b) Resource Filters: Running after authorization but before model binding, these wrap the rest of the pipeline. They are ideal for "outer-layer" tasks like caching or measuring total request performance.
c) Action Filters: These execute immediately before and after a controller action method is called. They can be used to manipulate input arguments, validate model state, or log action-specific metadata. (Note: These are not supported in Razor Pages; use IPageFilter instead).
d) Exception Filters: These are triggered only when an unhandled exception occurs during action execution or result rendering. They are used for centralized error logging and returning friendly error responses.
e) Result Filters: These run before and after the execution of the action result (e.g., before JSON is written to the response or a view is rendered). They are often used to add custom HTTP headers or wrap responses in a standard format. 
=====================================================================
Action Filter:-
--------------------
i)  OnMethodExecuting -> It runs before action method execution.
ii) OnMethodExecuted -> It runs after action method execution.
using Microsoft.AspNetCore.Mvc.Filters;

namespace Batch12PMCore_03_01_26.Filters
{
    public class CustomActionFilter : IActionFilter
    {
        public void OnActionExecuting(ActionExecutingContext context)
        {
            // Before Action Method...
           
        }
        public void OnActionExecuted(ActionExecutedContext context)
        {
            // After Action Method...
            
        }
    }
}
------------------------
Add filter in Program.cs [Middleware]
--------------------------------------------
builder.Services.AddMvc(options =>
{
    options.Filters.Add(new CustomActionFilter());
});

using Batch12PMCore_03_01_26.Models;
using Microsoft.AspNetCore.Mvc;

namespace Batch12PMCore_03_01_26.Controllers
{
    public class JqueryExampleController : Controller
    {
        public IActionResult Index()
        {
            return View();
        }

        [HttpPost]
        public JsonResult GetEmployee(string name, int age, string address)
        {
            EmployeeData emp = new EmployeeData
            {
                name = name,
                age = age,
                address = address,
                datetime = DateTime.Now.ToString()
            };
            return Json(emp);
        }

    }
}
